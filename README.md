# Aprendendo a usar o GitHub Copilot 🤖

Este repositório foi criado com o objetivo de registrar meus primeiros passos, testes e práticas utilizando a ferramenta **GitHub Copilot** no auxílio ao desenvolvimento de código.

## 📌 Sobre o Projeto

O repositório contém scripts simples em **Python** utilizados para testar as funcionalidades de autocompletar, sugestão de código e resolução de dúvidas oferecidas pela inteligência artificial.

## 📁 Estrutura do Repositório

* **`AprendendoUsarGitHubCopilot/`**
  * `Teste1.py` - Teste inicial de comandos e sugestões do Copilot.
  * `Teste2.py` - Exercícios e práticas de lógica utilizando a IA.
  * `Teste3.py` - Resolução de dúvidas e testes de funções.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 🐍
* **Ferramenta de IA:** GitHub Copilot
* **Plataforma:** GitHub
